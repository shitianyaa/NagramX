# 2026-08-05 普通视频定时播放器状态修复

## 原始问题
- 用户确认：选择定时关闭后退出全屏属于正常逻辑，但希望视频像音频一样收纳到顶部迷你播放器，便于查看播放列表和定时剩余时间。
- 当前表现：退出全屏后顶部不显示普通视频；再次进入视频全屏时定时剩余时间不显示。

## 根因
- `FragmentContextView.checkPlayer()` 将 `messageObject.isVideo()` 直接视为不可展示媒体。
- 普通视频转回 `PhotoViewer` 时调用 `MediaController.cleanupPlayer(..., transferPlayerToPhotoViewer = true)`，该路径先清空 `videoBackgroundPlayback` 和视频定时器状态。
- `PhotoViewer` 关闭时会清空本地定时器，但重进全屏没有从 `MediaController` 同步仍有效的后台定时器状态。
- `AudioPlayerAlert` 的媒体类型检查只接受音乐和语音，普通视频无法复用列表弹层。

## 修复清单
- [x] 保留后台视频转回全屏时的定时器状态并同步剩余毫秒数。
- [x] 顶部 `FragmentContextView` 展示普通视频、播放/暂停、定时剩余时间。
- [x] 顶部点击普通视频打开可切换列表的播放器弹层。
- [ ] 相关静态检查与 Android 编译。

## 本轮审查与修复
- 修复 `PhotoViewer` 转回 `MediaController` 时暂停状态和定时器状态不同步的问题，避免退出全屏后定时器或播放进度丢失。
- 普通视频复用顶部迷你播放器和 `AudioPlayerAlert` 列表，支持视频行、播放/暂停、拖动、快进/快退和播放速度。
- 原生媒体通知补充视频时长、进度、速度、播放/暂停和播放列表前后切换；兼容播放器尚未返回时长的回退值。
- 顶部视频文案使用视频发送者/视频标题，定时剩余时间随进度通知更新。

- 用户反馈：开启视频定时后，顶部迷你播放器在当前会话滑动或返回时消失；安卓原生媒体控制的上一条/下一条对视频不稳定，可能与目标视频未下载有关。

## 本轮根因与修复
- `ChatActivity.updateMessagesVisiblePart()` 在后台视频仍被视为会话内播放时，会重新定位旧的视频容器；滑动后可能遮挡、触发错误的可见性处理。现在后台视频跳过该容器定位。
- `ChatActivity.onRemoveFromParent()`、`updateTextureViewPosition()` 和会话重挂载路径会保留后台视频播放器，清理或重新绑定仅限前台视频。
- `MusicPlayerService` 在视频切换后刷新媒体会话；下载中的视频仍保留原生上一条/下一条动作；视频上一条不再先重播当前项；离线时未缓存的后台视频也会进入选择后下载/流式播放流程。
- 媒体服务收到普通前台视频的播放通知时不再创建后台通知，避免旧服务切换期间状态串线。
